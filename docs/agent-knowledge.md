# Журнал подтверждённых знаний агента по 1С

Этот файл хранит повторно полезные технические выводы. Перед работой ищите записи по области, симптому и названию механизма 1С.

## Формат записи

```text
### YYYY-MM-DD — Краткое название

- Область: подсистема, язык или инструмент.
- Контекст/симптом: при каких условиях проявилось.
- Подтверждённый вывод: что установлено.
- Проверка: как вывод был подтверждён.
- Практическое правило: что агент должен делать в дальнейшем.
```

## Записи

### 2026-08-08 — Выходной параметр метода `Свойство()` должен быть определён

- Область: встроенный язык 1С, работа со структурой и методом `Свойство()`.
- Контекст/симптом: синтаксическая проверка кода, в котором переменная передавалась вторым параметром метода `Свойство()` без предварительного определения.
- Подтверждённый вывод: переменную, используемую как выходной второй параметр `Свойство()`, необходимо предварительно определить.
- Проверка: особенность выявлена синтаксической проверкой; после объявления переменных проверку следует повторить.
- Практическое правило: перед вызовом `Структура.Свойство(ИмяСвойства, Значение)` объявлять или иным образом определять переменную `Значение`; не запускать обновление конфигурации до успешной повторной синтаксической проверки.
