# Журнал подтверждённых знаний агента по 1С

Этот файл хранит повторно полезные технические выводы. Перед работой ищите записи по области, симптому и названию механизма 1С.

## Формат записи

```text
### YYYY-MM-DD — Краткое название

- Область: подсистема, язык или инструмент.
- Контекст/симптом: при каких условиях проявилось.
- Подтверждённый вывод: что установлено.
- Проверка: как вывод был подтверждён.
- Практическое правило: что агент должен делать в дальнейшем.
```

## Записи

### 2026-08-08 — Безопасная проверка необязательных свойств структуры

- Область: встроенный язык 1С, работа со структурой и методом `Свойство()`.
- Контекст/симптом: синтаксическая проверка кода с выходным параметром `Свойство()` и ошибка выполнения `Поле объекта не обнаружено`, когда результат `ПрочитатьJSON()` не содержал необязательное поле внешнего API.
- Подтверждённый вывод: прямое обращение к отсутствующему свойству структуры завершает выполнение исключением. Перед чтением необязательного свойства его наличие нужно проверять методом `Свойство()`; переменная, используемая как выходной второй параметр этого метода, должна быть предварительно определена.
- Проверка: требование к выходному параметру подтверждено синтаксической проверкой 1С; отсутствие свойства воспроизведено фактической трассировкой выполнения и сопоставлено с исходным кодом прямого обращения к полю, которое официальная документация внешнего API определяет как необязательное.
- Практическое правило: данные JSON внешних систем считать неполными по умолчанию. Перед чтением необязательного поля вызывать `Структура.Свойство(ИмяСвойства, Значение)` с заранее определённой переменной `Значение`, отдельно проверять заполненность и формат значения и не запускать обновление конфигурации до успешной повторной синтаксической проверки.

### 2026-08-08 — Смещение `Сред()` после двухсимвольного префикса

- Область: встроенный язык 1С, разбор строковых кодов.
- Контекст/симптом: из строки с идентификатором применения `01` извлекался 14-символьный GTIN выражением `Сред(Строка, ПозицияПрефикса + 3, 14)`; первая цифра GTIN терялась, а в результат попадал следующий за GTIN символ.
- Подтверждённый вывод: позиции символов в строковых функциях 1С отсчитываются с единицы. Если `Найти()` вернул позицию начала двухсимвольного префикса, данные сразу после него начинаются с `ПозицияПрефикса + 2`.
- Проверка: смещение подтверждено подсчётом позиций на формате `01` + 14 символов GTIN и сопоставлением с исходным кодом, в котором рядом был сохранён исправленный вариант `+ 2`.
- Практическое правило: при извлечении подстроки после найденного префикса прибавлять длину префикса, а не длину плюс один; проверять граничные позиции на минимальном тестовом примере.
