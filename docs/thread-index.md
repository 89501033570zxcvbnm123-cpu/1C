## Правило использования

1. Определить проект и тему текущей задачи.
2. Найти строку по названию, ID или ключевому слову.
3. Сначала прочитать совпадения в `docs/agent-knowledge.md`.
4. Полную историю задачи читать только при нехватке подтверждённого контекста.
5. После нового подтверждённого устойчивого вывода обновить журнал; индекс менять только при появлении новой самостоятельной темы или переименовании задачи.
